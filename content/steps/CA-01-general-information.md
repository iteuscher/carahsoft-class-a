## What is FedRAMP?

[Draft] A U.S. government program that standardizes security assessment and certification of cloud services used by federal agencies, built on a "do once, use many" model.

## What is FedRAMP 20x?

[Draft] FedRAMP's modernized certification pathway, built around Key Security Indicators and machine-readable packages.

## What is FedRAMP 20x Class A?

Class A is a FedRAMP 20x certification path for providers who have completed a recognized security assessment under another framework. Instead of starting a federal authorization from zero, you bring your existing assessment, map it to a defined subset of FedRAMP rules, and publish the results in a machine-readable certification package.

## Where Class A fits

[Draft] After completing Class A, you must schedule a Class B or Class C assessment **within 2 years of your Class A listing**. Once you have 6 months of evidence at Class C, you can begin moving to Class D. Learn more: [What is Class B?](https://www.paramify.com/blog/fedramp-class-b) and [Class C vs Class D](https://www.paramify.com/blog/fedramp-class-c-vs-class-d).
